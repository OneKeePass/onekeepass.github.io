OneKeePass

OneKeePass Password Manager


OneKeePass is a cross-platform, open-source password manager for KeePass-compatible KDBX 4.x databases. It keeps passwords and other sensitive information in a single encrypted file that you can store locally or with the storage provider of your choice. Your database is protected by a master key and encrypted using AES-256 or ChaCha20.

OneKeePass is available for Windows, macOS, Linux, iOS, and Android. It works fully offline, and you decide where your password database files are stored.

Features

  • Create and use any number of KeePass-compatible databases
  • Organize entries by type, category, or the standard group tree
  • Create reusable custom entry types and add custom text, Boolean, or date fields
  • Organize custom fields into sections and attach files to entries
  • Protect a database with a key file, with or without a master password
  • Generate passwords and Diceware passphrases
  • Generate and use time-based one-time passwords (TOTP)
  • Merge databases, clone or copy entries, and move entries or groups
  • Use light or dark themes and multiple languages
  • Upload custom icons or fetch them from a URL or favicon
  • Open databases directly from SFTP and WebDAV servers
  • Store remote server credentials as SFTP Connection or WebDAV Connection entries
  • Use built-in entry types for SSH keys, identities, passports, and driver licenses
  • Import CSV exports from popular password managers and browsers on desktop

Desktop features

  • Quickly unlock with Touch ID on macOS or Windows Hello on Windows
  • Use Auto-Type to send credentials to other applications on macOS
  • Use OneKeePass as an SSH agent in Agent Mode or with an existing system agent in Client Mode
  • Connect the OneKeePass browser extension for password autofill and passkey registration and authentication

Mobile features

  • Quickly unlock with Face ID on iOS or fingerprint/face unlock on Android
  • Autofill usernames, passwords, and one-time verification codes
  • Use passkeys for passwordless registration and sign-in on iOS 17+ and Android 14+
  • Protect the app with a PIN
  • Open linked or child databases
  • Detect external database changes and merge them
  • Search all entries and sort by title, creation time, or modification time

Browser extensions

The OneKeePass browser extension integrates the desktop app with supported browsers for password autofill and passkeys. It is currently available for:

  • Firefox
  • Chrome
  • Brave

OneKeePass is developed primarily in ClojureScript and Rust. The desktop app uses Tauri, React, and MUI; the mobile apps use React Native, Swift, and Kotlin alongside the shared Rust core.
